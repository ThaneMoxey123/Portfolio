# Jack Moxey Portfolio — Version 8

Static portfolio starter designed for direct deployment to GitHub Pages.

## Files
- `index.html` — site structure/content
- `styles.css` — responsive design system and layouts
- `script.js` — section rail, mobile menu and gallery interactions

## Before publishing
1. Replace `hello@example.com` in `index.html` with your real contact email.
2. Replace the About photo placeholder with your own image.
3. Replace the concept project artwork/placeholders with real project screenshots.
4. Update project links (`href="#"`) when case-study pages exist.
5. Test on mobile before replacing the live site.

## GitHub Pages / custom domain
This build uses relative file paths, so it can be dropped into the root of an existing GitHub Pages repository. Keep your existing `CNAME` file if your custom domain depends on it.

If your current repository contains a `CNAME`, **do not delete it** when replacing the other site files.
